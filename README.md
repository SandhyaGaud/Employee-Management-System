# Employee-Management-System

A Java-based web application for managing employee records.

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- HTML
- CSS

## Day 1 — Create Employee

- Connected Java with MySQL using JDBC
- Created Employee model
- Created database connection
- Created Add Employee form
- Implemented AddEmployeeServlet
- Implemented EmployeeDAO
- Added employee records to MySQL

## Day 2 — Read Employees

- Retrieved employees from MySQL
- Implemented `getAllEmployees()`
- Created EmployeeListServlet
- Created employeeList.jsp
- Displayed employees in an HTML table
- Added View All Employees button
- Added basic CSS styling
